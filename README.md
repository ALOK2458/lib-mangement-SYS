# Leaf & Ledger

A basic, dependency-free library management system for tracking a catalog, active loans, members, and recent activity.

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server:

```bash
python3 -m http.server 8000
```

The app stores newly added books and loan status in the browser's local storage.# lib-mangement-SYS
